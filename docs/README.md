# 项目文档

开发与验收以《开发文档 v1.0》为准；三份文档写于 claude.ai，需要手动导出后放在本目录。

| 放在本目录的文件名 | 来源 | 导出方式 |
| --- | --- | --- |
| `开发文档-v1.0.md` | https://claude.ai/artifact/RDQb12NaHMzca2q3Vmwjmw | 打开文档 → 文档名旁的菜单 → 导出 → Markdown |
| `技术方案修订稿-v1.1.md` | https://claude.ai/artifact/NemWKpnS1TBo16VsZu7Qp1 | 同上；此文档有两个分页，导出只保存当前打开的分页 |
| `评测数据集调研.md` | 同上一行文档的第二个分页“评测数据集调研” | 切到该分页后再导出一次 |
| `技术详细设计-v0.1.md` | https://claude.ai/artifact/BLMb4wbpLfb7nLhsFjYhZC | 同上 |
| `事实表样例.xlsx` | 已附带，与在线模板 https://claude.ai/artifact/JoWTm385CLfbhRDovzNhTP 的样例数据一致 | 正式数据请从在线模板下载为 xlsx |

导出的 Markdown 中，文档里的两张示意图会变成占位文字，不影响阅读。

## 文档之间的关系

- **开发文档 v1.0**：唯一的开发与验收依据，合并了后两份文档的全部决定。冲突时以它为准。
- **技术方案修订稿 v1.1**：产品定位与各项决定的来由；“评测数据集调研”分页记录了数据集许可证核查结果。
- **技术详细设计 v0.1**：开发文档的前身，保留作参考。

## 设计变更

在本仓库中做出的设计改动，记到 `设计变更记录.md`，以便同步回 claude.ai 上的开发文档。
