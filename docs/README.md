# 项目文档

| 文件 | 内容 |
| --- | --- |
| `开发文档-v1.0.md` | 开发与验收的唯一依据：需求、架构、模块边界、各节的验收项（AC-x-y）与第 16.1 节的硬性项 |
| `设计变更记录.md` | 在本仓库中相对开发文档做出的每一处设计改动、原因，以及是否已同步回开发文档 |
| `部署说明.md` | 精简版的部署步骤、备份恢复与演练记录 |
| `机器规格对照表.md` | 入库吞吐、内存与存储的实测，以及按规模外推的机器规格 |
| `能力矩阵-线上模型.md` | 准入检查（验证器误通过率与误拒率、Deep 正确率）的结果 |
| `三方对比报告.md` | 传统 Hybrid RAG、Always-Agent、Adaptive 在合成集上的对比 |
| `事实表样例.xlsx` | 16 个查询的小型事实表样例，用于冒烟测试与端到端试跑 |
| `评测集/` | 合成评测集（事实表 → 文档 → 标准答案）与人工抽检单，说明见其中的 README |

开发文档原写在 claude.ai 的文档里，`开发文档-v1.0.md` 是导出的 Markdown；原文里的两张示意图（查询执行状态机、16 周路线图）导出后是占位文字。开发文档合并了更早的《技术方案修订稿 v1.1》《技术详细设计 v0.1》与评测数据集调研的全部决定，那几份不随仓库公开。

## 设计变更

相对开发文档的设计改动记到 `设计变更记录.md`，“已同步到开发文档”一栏标明是否已改回开发文档；两者冲突时，以设计变更记录中较新的决定为准。
