# 合成评测集

开发文档第 14 节的“自建合成集”：中文评测，覆盖版本、时间、回溯、冲突、归档、权限与验证器扰动。可对外展示，须注明为合成数据。

## 合成集 v2（`合成集-v2.xlsx`，当前版本）

由 `factset/synth.py` 生成：生成器版本 2，种子 2026，比例 1.0。

```
python -m factset synth -o docs/评测集/合成集-v2.xlsx --seed 2026 --scale 1.0
```

`tests/test_synth.py` 核对这份文件与生成器的输出逐条一致。改了生成器就要升生成器版本、另存为新版本，不能覆盖旧版本。

与 v1 的区别只在问法：v2 中 786 条查询（约 39%，每类都有）用改写问法——把事实键换成口语、近义的说法，且不含原词，
如“一线城市住宿上限”问成“北上广深出差的酒店报销额度”；查询表“说明”列记“原词问法”或“改写问法”。
v1 的问法都含事实键原词，五种分词器召回完全相同，区分不出来（见下文 v1 一节）。文档、版本、事实、事件与 v1 相同。

| 项目 | 数量 |
| --- | --- |
| 文档 | 68 份：规范类制度 30 份（每份 1–4 个版本）、补充通知 14 份、季度费用分析报告 24 份（记录类） |
| 版本 | 110 个；生效日写法：正文写明 59、仅上传时间 16、无 11、不适用 24 |
| 事实 | 311 条；载体为正文、表格、图表 |
| 事件 | 22 个：归档 6、取消归档 3、权限变更 5、有效期更正（补录生效日）8 |
| 角色 | 5 个：普通员工、财务、人力资源、管理人员、法务 |

查询共 2000 条，按 14.3 的样本量生成（类别与条数同 v1，各类应拒答的条数略有不同）：

每个类别按编号哈希排序后，前 30% 为标定集（600 条），其余 70% 为测试集（1400 条），写在查询表的“集合”列。
阈值只在标定集上调，指标只在测试集上报。评测运行器用 `--split 测试` 选择测试集，用 `--per-type N` 每类抽 N 条试跑，
两种抽样都可复现。

### 内容来源

内容是自编的企业制度（14.2 的“其次是自编内容”），没有使用法律法规或国家机关文件作种子，也没有用模型改写措辞。

### 状态

- 程序检查全部通过：事实表校验 0 个问题；2000 个查询的程序答案与回填答案全部一致；
  Word、HTML 两种格式生成的 110 份文档都通过文档检查（0 个错误；16 个提示是另一取值碰巧出现在同一份文档里）。
- 人工抽检尚未完成（14.2 第 6 步）。抽检单是 `合成集-v2-抽检单.xlsx`：每类 5%，共 100 条，列出问题、提问条件、
  程序答案与依据事实。核对完“核对结果”一列后，v2 才算正式冻结。

## 合成集 v1（`合成集-v1.xlsx`，已被 v2 取代）

生成器版本 1（提交 e2d8b90）的输出，问法都含事实键原词。保留它，是为了能复现 2026-11-13 在它上面做的分词器对比：
测试集 1400 条中可计分 1073 条，五种分词器、仅关键词与关键词加向量两种方式召回都是 1003/1073（93.5%），
MRR 0.826–0.834；除版本差异类（0/70，需要 Deep 分别检索新旧版本）外各类召回都是 100%。
当前代码的生成器已是版本 2，`python -m factset synth` 不再生成 v1。
