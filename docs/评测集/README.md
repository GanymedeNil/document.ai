# 合成评测集

开发文档第 14 节的“自建合成集”：中文评测，覆盖版本、时间、回溯、冲突、归档、权限与验证器扰动。可对外展示，须注明为合成数据。

## 合成集 v1（`合成集-v1.xlsx`）

由 `factset/synth.py` 生成：生成器版本 1，种子 2026，比例 1.0。

```
python -m factset synth -o docs/评测集/合成集-v1.xlsx --seed 2026 --scale 1.0
```

`tests/test_synth.py` 核对这份文件与生成器的输出逐条一致。改了生成器就要升生成器版本、另存为 v2，不能覆盖 v1。

| 项目 | 数量 |
| --- | --- |
| 文档 | 68 份：规范类制度 30 份（每份 1–4 个版本）、补充通知 14 份、季度费用分析报告 24 份（记录类） |
| 版本 | 110 个；生效日写法：正文写明 59、仅上传时间 16、无 11、不适用 24 |
| 事实 | 311 条；载体为正文、表格、图表 |
| 事件 | 22 个：归档 6、取消归档 3、权限变更 5、有效期更正（补录生效日）8 |
| 角色 | 5 个：普通员工、财务、人力资源、管理人员、法务 |

查询共 2000 条，按 14.3 的样本量生成：

| 类别 | 条数 | 说明 |
| --- | --- | --- |
| 历史时点 | 300 | 含 5 条“那时尚无有效版本”的拒答 |
| 回溯 | 300 | 含 53 条“那时系统里还没有”的拒答；补录生效日前后的来源等级不同 |
| 冲突 | 300 | 补充通知与主制度取值不同；来源等级相同时全部列出并标“未验证”，不同时 explicit 优先 |
| 归档 | 300 | 归档前、归档期间（124 条应拒答）、取消归档后 |
| 权限边界 | 300 | 无权角色应拒答（98 条），有权角色、权限变更前后 |
| 当前生效 | 100 | |
| 版本差异 | 100 | 最近一次修订前后 |
| 无答案 | 100 | 与已有事实键相近、但事实表里没有的说法 |
| 图表 | 100 | 取值只在图片里，需要视觉模型 |
| 验证器 | 100 | 给出结论：取值正确（支持）或被改动（不支持） |

每个类别按编号哈希排序后，前 30% 为标定集（600 条），其余 70% 为测试集（1400 条），写在查询表的“集合”列。
阈值只在标定集上调，指标只在测试集上报。评测运行器用 `--split 测试` 选择测试集，用 `--per-type N` 每类抽 N 条试跑，
两种抽样都可复现。

### 内容来源

内容是自编的企业制度（14.2 的“其次是自编内容”），没有使用法律法规或国家机关文件作种子，也没有用模型改写措辞。
